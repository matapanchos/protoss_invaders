# Protoss invaders

An Starcraft 2 based shoot 'em up made with pygame in the process of learning to use the library.  
All assets are copyright to their respective owners.

Controls:

- Movement: Right and left arrow keys.
- Shoot: Space bar.

Objective: Try to kill all Void rays before they reach the bottom of the screen.

Hint: Optimize your bullets in screen, they aren't infinity.
